# Release Process

This document describes how to release new versions of `amazon-order-scraper` to npm.

## Automated Publishing

Releases are automated via GitHub Actions. When a git tag matching `v*` is pushed, the CI pipeline automatically:

1. Checks out the tag
2. Runs all tests
3. Builds the package
4. Publishes to npm

## Release Steps

### 1. Ensure Tests Pass

```bash
cd mcp-server
npm test
npm run build
```

### 2. Update Version

Use `npm version` to bump the version and create a tag automatically:

```bash
# Patch release (1.0.0 → 1.0.1) - for bug fixes
npm version patch

# Minor release (1.0.0 → 1.1.0) - for new features
npm version minor

# Major release (1.0.0 → 2.0.0) - for breaking changes
npm version major
```

This will:
- Update `package.json` version
- Update `package-lock.json`
- Create a git commit
- Create a git tag (e.g., `v1.0.1`)

### 3. Push to GitHub

```bash
git push origin main --follow-tags
```

The `--follow-tags` flag pushes both the commits and tags.

### 4. Verify Publishing

Check that the workflow completed:
- Visit https://github.com/eshaffer321/amazon-monarch-sync/actions
- Confirm the "Publish to npm" workflow ran successfully
- Verify on npm: https://www.npmjs.com/package/amazon-order-scraper

## Manual Release (if automation fails)

If you need to publish manually without automation:

```bash
cd mcp-server
npm ci
npm run build
npm publish --access public
```

You'll need `NPM_TOKEN` env var set with a valid npm auth token.

## Versioning

This project follows [Semantic Versioning](https://semver.org/):

- **MAJOR** (x.0.0): Breaking changes to the API
- **MINOR** (0.x.0): New features, backwards compatible
- **PATCH** (0.0.x): Bug fixes, backwards compatible

## Checklist Before Release

- [ ] Tests passing locally: `npm test`
- [ ] Build succeeds: `npm run build`
- [ ] Changes are merged to `main`
- [ ] Version bump aligns with changes (patch/minor/major)
- [ ] Commit message describes the release (auto-generated by `npm version`)

## Examples

### Release a bug fix

```bash
cd mcp-server
npm version patch
git push origin main --follow-tags
# Publishes as v1.0.1
```

### Release new features

```bash
cd mcp-server
npm version minor
git push origin main --follow-tags
# Publishes as v1.1.0
```
